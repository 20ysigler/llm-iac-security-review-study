# LLM security review of Terraform: model, prompt, agent pattern, and reasoning

Data, code, and paper for **AI-Facilitated IaC Security Review: The Effects of Model Selection, Context Engineering, and Agent Orchestration on Vulnerability Detection** (Clifton Sigler, SANS Technology Institute, 2026).

## The question and the answer

Can a large language model take on part of the security review of Terraform, and which implementation choices matter: the model, the prompt, the agent pattern, or native reasoning?

Four models (Claude Opus 5, Claude Sonnet 5, GPT-5.6 Terra, and a DeepSeek Flash endpoint) reviewed six files of a mutated TerraGoat corpus, rewritten to reduce recall from training data, across five prompt variants and four orchestration patterns, five repetitions each: 36 configurations, 1,080 scored runs, 1,540 API calls, about $27 at list prices. Every claim a model made was scored against 52 Checkov-derived findings.

**Model choice mattered most, and what it changed was recall.** With the same prompt and a single call:

| Model | Precision | Recall | F1 | F1 95% CI | TP | FP | FN | Paired F1 difference vs Opus (p) |
|---|---|---|---|---|---|---|---|---|
| Claude Opus 5 | 0.684 | 0.692 | 0.688 | [0.636, 0.735] | 180 | 83 | 80 | — |
| Claude Sonnet 5 | 0.835 | 0.508 | 0.632 | [0.576, 0.682] | 132 | 26 | 128 | −0.057 (<0.001) |
| DeepSeek Flash | 0.696 | 0.492 | 0.577 | [0.517, 0.633] | 128 | 56 | 132 | −0.112 (<0.001) |
| GPT-5.6 Terra | 0.871 | 0.312 | 0.459 | [0.405, 0.512] | 81 | 12 | 179 | −0.229 (<0.001) |

The cheaper models were not wrong more often; they found less. Prompt design and multi-agent patterns helped only the two weakest models, by five to eight F1 points, lowered the two strongest, and cost up to 3.6 times as much. Native reasoning helped no model. An audit of the 177 claims the scorer rejected in the model comparison found that a third were real weaknesses the Checkov-derived ground truth could not see and two-fifths were true observations outside the study's criterion; adjusted precision ranged from 0.77 to 0.96 and the ranking did not change.

Every table in the paper is in [`RESULTS.md`](RESULTS.md), and every number in it recomputes from the raw run files (see below).

## Reproduce the tables without an API key

```bash
git clone https://github.com/20ysigler/llm-iac-security-review-study.git
cd llm-iac-security-review-study
python3 harness/verify_paper.py            # recomputes every figure in RESULTS.md from harness/results/ (241 checks)
python3 harness/build_results.py > /tmp/RESULTS.md && diff /tmp/RESULTS.md RESULTS.md   # regenerates the tables
python3 harness/rescore.py                 # rebuilds harness/scored/ from the raw runs
```

The harness is Python 3.11 standard library only; `requirements.txt` lists Checkov 3.3.11, needed only to re-validate the corpus:

```bash
pip install -r requirements.txt
python3 harness/validate_mutation.py       # Checkov on the mutated corpus: 95 failed checks, identical to the original
```

Re-running the models needs `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, and `DEEPSEEK_HOST_KEY` in the environment and about $27 at August 2026 list prices; `run_sets23.sh`, `run_reasoning.sh`, `run_rerun.sh`, `run_rerun2.sh`, `run_grid.sh`, and `run_reasoning_rerun.sh` are the drivers that produced the data, in that order. `run_experiment.py` skips a run whose result file already exists, so a partial rerun is safe.

## How a run is scored

A run is one review of one file. The model answers through a fixed JSON schema (resource, issue category, description, severity, CWE). A claim matches a ground-truth finding when it names the same resource and its category or description contains at least one cue from the finding's category vocabulary, or when it carries the same CWE on the same resource; matching is greedy and one-to-one. Unmatched claims are false positives, unmatched findings are false negatives. Precision, recall, and F1 are computed from counts pooled over a configuration's 30 runs; confidence intervals resample the 30 runs; paired comparisons between two configurations resample the 30 file-and-repetition units they share. Section 2 of the paper and `harness/match.py` have the details, and `harness/fp_review/` shows what the 177 rejected claims of the model comparison actually were.

## Known limitations

`paper/KNOWN_LIMITATIONS.md` lists what a reviewer should weigh: a single rater for the ground truth and the adjudication, 22% of accepted matches resting on one vocabulary cue, two mutation defects left in the corpus, the chunked pattern's header effect, the DeepSeek reasoning arm rerun nine days after the rest of the study, and 35 uncorrected paired tests with conclusions drawn at p ≤ 0.01.
