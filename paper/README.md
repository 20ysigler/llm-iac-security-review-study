# The paper

*AI-Facilitated IaC Security Review: The Effects of Model Selection, Context Engineering, and Agent Orchestration on Vulnerability Detection* (Clifton Sigler, SANS Technology Institute, 2026) has been submitted as a draft and is awaiting advisor feedback and presentation. The accepted version will be added here once SANS has accepted it; until then the paper is not distributed from this repository.

What is here now:

- `KNOWN_LIMITATIONS.md`: the open items a reviewer of the paper should weigh, with what would settle each and what it would cost.
- `../RESULTS.md`: every table the paper reports, regenerated from the run files by `harness/build_results.py` and checked by `harness/verify_paper.py`.

The paper cites this repository at tag `v1.0-submission`.
