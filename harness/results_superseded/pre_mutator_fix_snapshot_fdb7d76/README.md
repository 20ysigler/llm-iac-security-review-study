# Runs on the first mutated corpus

The first version of `mutate_corpus.py` produced an invalid ACL value in s3.tf and double-substituted some identifier strings in db-app.tf. The rule was corrected, the corpus regenerated and re-validated against Checkov (95 failed checks, unchanged), and every run on the two affected files, 180 runs across the 18 configurations that existed at the time, was repeated; the other four files were byte-identical before and after and their runs stand (paper, Section 3.4.1). `results/` holds the superseded runs and `terragoat_mut/` the two pre-fix files. They are not part of the 1,080 reported runs.
